# Matriz de Permisos SigeSchool Pro

| Recurso | Administrador (1) | Rector (2) | Coordinador (3) | Secretaria (4) | Docente (5) |
| :--- | :---: | :---: | :---: | :---: | :---: |
| Usuarios | CRUD | R | - | - | - |
| Estudiantes | CRUD | CRUD | R | CRUD | R |
| Curricular (PEI) | CRUD | CRUD | R | R | R |
| Curricular (Aula) | CRUD | CRUD | CRUD | R | CRUD |
| Pagos | CRUD | R | - | CRUD | - |
| Calificaciones | CRUD | R | R | - | CRUD |
| Hojas de Vida (CV) | CRUD | CRUD | R | CRUD (Docentes) | R (Propia) |

**Convenciones:**
- **C**: Create (Crear)
- **R**: Read (Leer)
- **U**: Update (Actualizar)
- **D**: Delete (Eliminar)
- **CRUD**: Todos los permisos.
